# 坦克大战 · Battle City

一个用原生 HTML5 Canvas + JavaScript 实现的经典**坦克大战**网页游戏，零依赖，双击 `index.html` 即可游玩，也支持在线试玩。

## 🎮 玩法

- 操控己方坦克，消灭所有敌人，**保护底部中央的基地（🏠 旗帜）**
- 基地被摧毁或生命耗尽即游戏失败
- **无尽关卡**，难度随关卡不断攀升

## 🎚️ 难度选择

开始菜单可自选难度（← → 选择，空格/回车 开始，或直接点击）：

| 难度 | 特点 |
| --- | --- |
| 🟢 简单 | 敌人少、慢、弱，适合上手 |
| 🟡 普通 | 标准挑战 |
| 🔴 困难 | 敌人多、快、强，Boss 更肉 |

无尽关卡，敌人数量/速度/类型随关卡持续递增。

## 👾 Boss 战

每 **5 关**（第 5、10、15…关）会出现一个 **Boss** —— 体型 2×2、带血条的巨型坦克，缓慢下压并发射三连弹幕。击破 Boss +1000 分。

## ⌨️ 操作

| 按键 | 功能 |
| --- | --- |
| `↑` `↓` `←` `→` / `W` `A` `S` `D` | 移动 |
| `空格` / `J` / `回车` | 射击 |
| `P` | 暂停 / 继续 |
| `M` | 静音 |

## 🧱 地图元素（15×15 大地图）

- 🟤 **砖墙**：可被子弹摧毁
- ⬜ **钢板**：普通子弹无法摧毁（满级火力可穿透）
- 💧 **水**：阻挡坦克、子弹可穿过
- 🏠 **基地**：被击中则游戏失败

## ⭐ 道具

- ⭐ **星星**：提升火力（最多 3 级，3 级可击穿钢板）
- 🛡️ **护盾**：8 秒无敌
- 💣 **手雷**：消灭场上所有敌人
- ⛑️ **钢盔**：基地临时披上钢板
- ❤️ **生命**：+1 条命

## 🚀 运行

直接用浏览器打开 `index.html`，或在线访问 GitHub Pages 地址，无需任何构建或依赖。
